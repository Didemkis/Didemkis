## Hi, I'm Didem Kış 👋

I study web vulnerabilities from three angles: how they work, what traces they leave for defenders, and which controls can reduce the risk. This perspective is shaped by my offensive security experience, my work teaching SOC fundamentals, and my ISO/IEC 27001 and 42001 Lead Auditor certifications.

Right now, I'm working through authentication, injection, server-side, and client-side vulnerabilities, documenting the mechanism behind each one. AI security is my next focus, especially prompt injection, LLM and RAG risks, and supply chain poisoning.
